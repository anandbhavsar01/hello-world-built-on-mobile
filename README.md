# Hello World, built on mobile

A tiny iOS "Hello, World!" app that greets you in eight languages.

## Run it right now (any iPhone)

`web/index.html` is a web version of the app. Open it in Safari, then tap
**Share → Add to Home Screen** to launch it like an app.

## Run the native SwiftUI app

`HelloWorld.swiftpm` is a Swift Playgrounds app package.

- **iPad:** open it in the free Swift Playgrounds app and tap Run.
- **Mac:** open it in Xcode (or Swift Playgrounds), plug in your iPhone,
  choose it as the run destination, and press Run. A free Apple ID works for
  signing; you'll need to trust the developer profile on the phone under
  Settings → General → VPN & Device Management.

Native iOS apps can't be installed on an iPhone straight from a phone browser.
Apple requires them to be signed and installed from a Mac, an iPad, or
TestFlight / the App Store.
